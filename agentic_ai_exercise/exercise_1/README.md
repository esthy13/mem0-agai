## Exercise 1: Exploring Agentic AI with AgentScope

### Goal
The goal of this exercise is to gain hands-on experience with the [AgentScope](https://docs.agentscope.io/) library. You will learn core concepts of agentic workflows and implement a specific agentic task or prompting technique within this framework.

### Task Selection
1.  Navigate to the **GitLab Issues** for this repository.
2.  Browse the available tasks defined in the issues.
3.  As a group, select **one** task and assign yourselves to the corresponding selection in Moodle (maximum number of groups). This selected task will be your Exercise 1.

### Workflow & Submission
To work on the exercise, follow these steps:
1.  **Merge Request:** Create a Merge Request (MR). Assign yourself to the MR.       
2.  **Create a Branch:** Create a new branch for your work from the Merge Request page from the `main` branch.
3.  **Naming Convention:** Both your **branch name** and the **folder** you create within `exercise_1/` MUST follow this pattern:
    `{exercise_short}_group_{character}`
    *   `{exercise_short}` is provided in the GitLab issue description.
    *   `group_{character}` represents your assigned group (e.g., `group_a`).
    *   Example: `react_group_a`

### Implementation Requirements
-   **Framework:** Use the AgentScope library for your implementation.
-   **Original Research:** You should study the original paper and existing implementations related to your assigned task.
-   **Evaluation:** Implement the task and evaluate your solution. For example, you can use the datasets or tasks described in the original paper/implementation to verify your results.
-   **Code Adaptation:** You may adapt existing code from other sources, but you must respect and adhere to their original **licenses**.
-   **Alternative Ideas:** If your group has ideas for other tasks or prompting techniques you'd like to implement instead, please reach out to the instructor for approval.
